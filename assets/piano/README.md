# Grand piano samples

`salamander-v1.pvpiano` is the grand piano the app plays your notes on (Audio → Sound → Sound from → Grand piano).
The app downloads it once, the first time it's picked.

It is made from **Salamander Grand Piano V3** by **Alexander Holm**, licensed under
[Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/)
(source: https://archive.org/details/SalamanderGrandPianoV3, FLAC remap: https://github.com/sfzinstruments/SalamanderGrandPiano).

Changes: 6 of the 16 loudness layers kept; silence before each note trimmed; tails shortened with a fade; encoded as
Ogg Opus; packed into one file by `tools/piano-pack/make.py`.
